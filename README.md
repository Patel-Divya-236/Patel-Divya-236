### 🧠 [SmartML Studio](https://github.com/Patel-Divya-236/smartml-studio)

An end-to-end ML platform that guides you from raw CSV to explained prediction. Every
module is an **advisor**, not an autopilot — it recommends the next step with a
confidence score and a plain-English reason, and you decide.

Includes **SVM and kNN written from scratch in NumPy**, a hybrid voting ensemble, and
SHAP explanations for individual predictions.

`Python` `Streamlit` `scikit-learn` `XGBoost` `SHAP`

</td>
<td width="50%" valign="top">

### 🎬 [CineCloud](https://github.com/Patel-Divya-236/Movie_Booking_System_)

A cloud-native movie ticket booking system built end-to-end on AWS. Live TMDB catalogue,
interactive seat selection with locking so two people can't buy the same seat, Razorpay
checkout, and QR-coded PDF tickets by email.

Runs on EC2 with DynamoDB behind it and **an IAM role instead of stored credentials**.

`Node.js` `Express` `AWS EC2` `DynamoDB` `SNS` `JWT`
